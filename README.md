# Omkar Sonpitre Portfolio

Omkar Sonpitre's responsive portfolio site, built with HTML, CSS, JavaScript and the supplied media assets.

**Live website:** https://ankitparsutkar.github.io/

## GitHub Pages

The site is published from the `main` branch root. Updates pushed to that source are published by GitHub Pages.

The main files are `index.html`, `style.css`, `script.js`, `sitemap.xml`, and the `assets/` directory.
